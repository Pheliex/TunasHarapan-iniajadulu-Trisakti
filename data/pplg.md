# PPLG — Pengembangan Perangkat Lunak dan Gim

## Tentang
Pembelajaran PPLG SMK Telekomunikasi Tunas Harapan dirancang melalui konsep Teaching Factory (TEFA) dan Deep Learning. Kurikulum disinkronkan bersama perusahaan dan guru melakukan upskill/reskill.

Website juga menggunakan istilah PPLG/RPL karena RPL merupakan konsentrasi keahlian di dalam program tersebut.

## Materi yang Dipelajari
- Pemrograman Dasar
- Pemodelan Perangkat Lunak
- Basis Data
- Pemrograman Berorientasi Obyek
- Pemrograman Web dan Perangkat Bergerak

## Sertifikasi
PPLG/RPL bekerja sama dengan Lembaga Sertifikasi Profesi (LSP) Teknologi Digital untuk sertifikasi profesi Junior Web Developer pada setiap akhir pendidikan.

SMK Telekomunikasi Tunas Harapan disebut sebagai salah satu Tempat Uji Kompetensi Mandiri dari LSP Teknologi Digital.

## Teaching Factory
Konsentrasi RPL dalam PPLG bekerja sama dengan PT Universal Big Data (UBIG) Malang. Fokus TEFA yang disebut website antara lain:
- FullStack Developers
- Game Developer

Konsep pembelajaran menggunakan production-based learning, dengan fokus pada produksi dan bisnis.

## Peluang Kerja
- Web Programmer
- Mobile Programmer
- Front End Programmer
- Back End Programmer
- Digital Marketing

## Informasi Tambahan
Pada 2025, jurusan PPLG melakukan pelatihan upskilling guru dengan fokus Web Fullstack melalui konsorsium industri.
